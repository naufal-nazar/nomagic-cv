# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas and evidence rather than people, and keep discussions free of harassment. Report unacceptable behaviour privately through [GitHub security advisories](https://github.com/naufal-nazar/nomagic-cv/security/advisories/new) or to the maintainer via GitHub. Maintainers may remove content or contributors that break these standards.
